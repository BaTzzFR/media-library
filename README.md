# Médiathèque

Application web de gestion d'une médiathèque 
développée en **PHP** avec une base de données **PostgreSQL**,
réalisée dans le cadre des TD du module **R3.01**.

## Architecture

Le projet suit une architecture **MVP (Modèle - Vue - Présentateur)**,
avec `index.php` qui joue le rôle de routeur.
